# Internal creative content review

An authorized Marketing writer can request review of an exact creative revision, with a rationale, explicit confirmation and one to five distinct reviewer IDs in order. The requester cannot review their own request. A pending request is unique per creative. Naming a reviewer does not grant access: current Marketing read/approve rights, campaigns capability, assignment order and original source visibility are required. Existing owned records, scoped atomic persistence, audit/outbox and idempotency contracts are reused.

A decision binds the current review revision and the exact source fingerprint. Source changes invalidate pending approval. Reject and withdraw retain reasons/history; only the requester can withdraw. Final approval atomically marks the creative APPROVED_INTERNAL and the review complete. Approved source content is immutable through normal editing and keeps delivery_state NOT_PUBLISHED. A changed variant requires a new draft. No provider, campaign activation, email or external publication is invoked.

Private review copies follow current source ownership in native lists/get/export and shared Data projections. An assigned reviewer without source visibility cannot read the content. Replaying a completed command still checks current authority/access. Failed persistence restores source, review, idempotency, audit and outbox state. Existing records remain exportable with proper permissions when the module is disabled.

The Marketing workspace exposes requests, exact content, sequential decisions, rejection and withdrawal. Unit tests and real member-session HTTP tests cover source drift, self/out-of-order denial, role/capability checks, private copies, atomic final approval, immutable approved content, replay, failure rollback and encrypted restart mid-review and after completion. Reviewer selection UI uses explicit user IDs; it does not claim directory invitations or newly granted access. Provider publication, broader creative version management and browser interaction remain unproven or unimplemented.
