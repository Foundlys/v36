# Explicit Sales probability scenarios

POST `/api/sales/forecast/scenarios/query` is a read-only projection requiring current Sales forecast and opportunities access. It reuses the existing permission-filtered forecast. The caller supplies normal forecast filters and an explicit scenario title, rationale and 1–200 per-opportunity probability adjustments. Each adjustment binds an accessible open opportunity ID and exact current revision. Duplicates, foreign/out-of-scope records, closed outcomes, unsupported fields and probabilities outside integer basis points 0–10000 are rejected.

Amounts, statuses and recorded probabilities are never changed. Scenario weighting uses exact integer arithmetic with per-record half-up cent rounding. Currencies remain separate. Recorded won amounts remain user-recorded Sales outcomes, not accounting revenue. A scenario is a user assumption, not calibrated statistical confidence. Missing eligible probabilities or excluded source records produce null full totals/comparisons; filling a missing probability can make a scenario calculable without inventing a baseline delta. Known subtotals remain explicitly named.

The existing confirmed immutable forecast snapshot action also accepts the scenario. Its fingerprint binds all current baseline source/target data and the exact assumptions. Changed source revisions, changed assumptions, stale fingerprints and idempotency conflicts are refused. Existing current-source ownership checks protect historical snapshot read/export. Failed persistence rolls back the snapshot, idempotency and audit/outbox state. Encrypted restart preserves it.

The actual Sales forecast surface supports selecting explicit per-record probabilities, rationale, scenario comparison and saving. Baseline values and quotas are displayed separately from scenario totals. At most 200 visible open opportunities are selectable in the editor, with an explicit narrower-period notice for larger lists. Input changes invalidate displayed calculations. Keyboard/viewport/browser interaction remains unproven. Hierarchies, amount/date adjustments, calibrated forecast confidence and broader scenario workflows remain open.
