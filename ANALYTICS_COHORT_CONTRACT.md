# Observed cohort retention

GET `/api/analysis/cohorts` is a read-only canonical projection. Current Analytics read, reports and events access are required before source retrieval. Existing event ACLs filter the source data first; hidden records contribute neither members, values, evidence nor invalid-record counts. No workflow or report is implicitly saved or executed.

The caller explicitly supplies `acquisition_event`, a different `return_event`, `identity_field` (customer_id, lead_id, anonymous_id or session_id), offset-bearing `from` and exclusive `to`. `interval_days` is 1, 7 or 30; `periods` is 1–12 following intervals. Unsupported filters are rejected. The maximum requested span is 366 days and the projection accepts at most 20,000 accessible retained source events. Larger histories require a future bounded/indexed query implementation; no large-tenant performance acceptance is claimed.

Membership uses each source/identity pair's earliest accessible acquisition event in retained history. Earlier acquisitions exclude that pair from the selected cohort range; this is not proof of the first lifetime acquisition or complete source history. Equal IDs from different sources are not merged. Invalid identities are excluded, event IDs are deduplicated, and only return events at or after the member's acquisition count. No person is inferred from an actor ID.

Fixed-duration intervals are anchored at `from`, independent of local DST. Period zero means return during the acquisition interval. Each cell counts distinct returning cohort members, divided by observed cohort size. The percentage is null until the whole interval is within the observed range, bounded by the requested `to` and current time. Zero is used only for a completed interval with observed members and no matching return. An empty source result has no fabricated cohorts.

Results include definition/version, period bounds, source names, freshness, excluded accessible record counts, source references and explicit truncation above 2,000 references. Provider verification is retained from canonical evidence, not invented. Source completeness, statistical confidence, comparison and trend are not estimated. This is a batch projection, not a realtime stream.

The actual Analytics page has a separate cohort form/table and evidence disclosure; it no longer sends the Cohorts link to generic historical aggregates. Failed requests and revoked capabilities clear the result. Fields and source text use DOM text insertion. Unit and authenticated Analysis-only HTTP tests cover arithmetic, interval edges, private records, revocation, duplicate events and encrypted restart. Browser/keyboard/viewport acceptance remains unproven. Saved cohort definitions, broader analytic models and cohort-specific ZERO tools remain future work.
