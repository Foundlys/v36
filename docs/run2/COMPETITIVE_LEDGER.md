# Run 2 competitive capability ledger

Discovery date: 2026-09-24. This is a current primary-source benchmark selection, not a measured ranking. Vendor descriptions establish comparison dimensions; they do not establish Foundly parity. All parity/superiority verdicts remain **UNVERIFIED** until matched task evidence exists. Existing Run-1 capability boundaries are retained.

| Area | Current benchmark and primary source | Foundly evidence-backed starting gap | Required comparison evidence |
| --- | --- | --- | --- |
| Enterprise assistants, orchestration and multilingual workflows | [Microsoft Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/) documents connected agents, knowledge, tools, evaluations and governance. | `server.js` selects one configured AI model, with protocol fallback; no independent specialist execution registry. | Multi-turn intent, safe execution, tool choice, locale parity, latency and cost on the same tasks. |
| Agent safety and governed business actions | [Salesforce Agentforce trust architecture](https://architect.salesforce.com/docs/architect/well-architected/guide/agentic-enterprise-trust.html) places mandatory approval checkpoints outside model reasoning. | Native Run-1 approval boundaries exist; Run-2 memory, agent and research paths need equivalent enforcement. | Current identity, exact action/revision, revoked permission, stale approval and injection scenarios. |
| Enterprise search and knowledge permissions | [Glean MCP security](https://docs.glean.com/administration/platform/mcp/security) describes scoped tools and identity-bound access. | Native knowledge retrieval is lexical/structured; no complete cross-source semantic search or current-source revalidation for all generated context. | Revocation after retrieval, tenant/user isolation, provenance, permission-filtered search and no unavailable-as-zero answers. |
| Memory and context | [LangGraph memory](https://docs.langchain.com/oss/javascript/concepts/memory) distinguishes profile and document memory with retrieval/update trade-offs. | Conversations and module text history exist; no unified eight-layer lifecycle; ZERO preferences are currently tenant-wide. | Supersession, expiry, deletion, conflicting facts, per-user preferences, source revalidation and bounded assembly. |
| Durable agent handoff and review | [LangGraph interrupts](https://docs.langchain.com/oss/javascript/langgraph/interrupts) documents interruption and resume. | Existing turn/review replay works for native modules; specialist cancellation and bounded DAG execution are absent. | Cancellation, independent verification, duplicate prevention, retry ceilings and unchanged authority after handoff. |
| Evaluation and regression | [Google agent evaluation](https://docs.cloud.google.com/gemini-enterprise-agent-platform/optimize/evaluation/agent-evaluation) separates cases, inference traces, scoring and refinement. | Many existing regression suites, but no permanent versioned Run-2 behavioral corpus or complete quality scoring. | Reproducible traces, source hashes, negative cases, independent judgments, real-model tasks and explicit unverified outcomes. |
| Procurement, Finance, Analytics and cross-domain intelligence | [SAP Joule agents](https://www.sap.com/products/artificial-intelligence/ai-agents.html) covers finance, spend, supply chain and customer experience. | Native module reasoning exists; model context uses bounded recent rows rather than question-driven cross-source evidence. | Hard causal/business questions, exact calculations, conflicting sources, cost/capital constraints and approved follow-up. |
| Voice conversation | [ElevenLabs conversation flow](https://elevenlabs.io/docs/eleven-agents/customization/conversation-flow) documents interruptions, silence handling and turn-taking. | Realtime transport and barge-in contracts exist; male/female modes and all-locale listening evidence are absent. | Representative male/female samples, three modes, eight locales, first-audio latency, interruption safety and independent listening. |
| Stack discovery | [ServiceNow discovery troubleshooting](https://support.servicenow.com/kb/kb?id=kb_article_view&sysparm_article=KB0657528) treats credentials and permissions as explicit discovery failure causes. | Connector catalog exists, but not a heterogeneous evidence/conflict model. | Multiple CRMs, revoked OAuth, undocumented schemas/webhooks, outages and source-of-truth conflicts without fabricated facts. |
| Automotive market intelligence | [Indicata Market Tracker](https://indicata.com/market-tracker/) exposes supply/demand comparisons and multi-year trends. | Real-source acquisition adapters and economics exist; provenance/time/geography knowledge and coherent multi-period scenarios need depth. | Capital, stock age, market observations, comparables, assumptions and reproducible margin recommendations. |
| Automotive inventory operations | [vAuto](https://www.vauto.com/) describes inventory sourcing, appraisal and pricing products. | Native Automotive contracts exist; current-provider/customer acceptance and measured business superiority remain unverified. | Matched dealer cases with evidence for acquisition, repricing, neglected leads and working-capital impact. |

The initial ledger maps every major Run-2 workstream to relevant comparison dimensions. Specific missing capabilities are reproduced before implementation; unsupported claims in marketing pages are not converted into acceptance requirements or independent performance facts. Additional primary sources are added only for concrete newly discovered gaps.
